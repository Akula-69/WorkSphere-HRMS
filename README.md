## 🛠️ Troubleshooting: If Something Goes Wrong

Sometimes things do not work perfectly on the first try. Here are common issues and how to fix them.

### Problem: The application will not start.

- **Solution:** Make sure you have a stable internet connection. The app needs to connect to the cloud to load. Also, try right-clicking the application icon and selecting **"Run as administrator"**.

### Problem: I see a blank or white screen.

- **Solution:** This usually means the app is still loading data from the cloud. Wait for 10-15 seconds. If the screen stays blank, close the app and reopen it.

### Problem: The download is very slow.

- **Solution:** Check your internet speed. You can also pause and resume the download. Make sure no other large downloads are running at the same time.

### Problem: I forgot my password.

- **Solution:** On the login screen, click **"Forgot Password?"** and follow the instructions sent to your email. You will be able to reset it in a few minutes.
